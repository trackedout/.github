Welcome to Tracked Out! We are a community of Hermitcraft fans who originally came together to track the entirety of Decked Out 2.
After countless hours of fine-tuning, testing, and improving, we are excited to finally open our Decked Out 2 server to everyone.
Our server is public, free to use, and open for your enjoyment!

Check out our website for more details at https://www.trackedout.org!


## Components
Tracked Out is made up of several different components all coming together to make this server possible:
- [Brilliance](https://github.com/trackedout/Brilliance) - Brilliance is the datapack that runs on each instance that handles data tracking, advancements, functions, dungeon setup, and misc moderator commands within the dungeon. It also powers the entire game config and is the only component published in our upcoming world download.
- [Dunga Dunga](https://github.com/trackedout/dunga-dunga-backend) - Dunga Dunga is the backend server that coordinates instances, holds the queue for players, and stores and logs events and data for all instances and the lobby to access.
- [Agronet](https://github.com/trackedout/agronet-fabric) - Agronet is the Fabric mod that runs on the instances to coordinate communication between Brilliance and Dunga Dunga
- [Citadel](https://github.com/trackedout/citadel) - Citadel is the Paper plugin that runs on the lobby for deck management, queuing, the crown shop, artifake viewing, and GM commands within the lobby.
- [Davy Bones](https://github.com/trackedout/davybones) - Davy Bones is our Docker and Tailscale setup that actually runs all the instances, lobby, builders and creative server, and more. All the server configs, plugin jars, world files, and everything needed to run our setup is stored here.
